# 公开版素材说明

## 随项目分发的内容

图片与封面由 `tools/generate_demo_media.py` 绘制，内容为色块、海面、太阳和几何房屋。画幅比例沿用各展示位置的需求。图内标注“原创演示”，不描绘或冒充真实人物。

节目保留原有资源 ID，以兼容场馆、收藏及任务引用。所有节目标题已改为“海风演示”，短片时长均为 8 秒。短片使用原创几何画面和本项目程序生成的器乐；没有歌曲采样、真人演唱或影视画面。

建筑、地形、植物、家具、角色、着色器和原有程序器乐来自本项目。公开素材的文件、大小、SHA-256 和许可证登记在 `data/public_asset_manifest.json`。

## 许可

项目原创资源与演示资源采用 MIT。`assets/audio` 根目录的三份基础环境 WAV 沿用 CC0，具体说明保留在同目录的 `SOURCE.txt`。字体 Noto Sans SC 使用 SIL OFL，许可原文保留在 `assets/fonts/OFL.txt`。

私人版中的真人照片、歌曲、MV、原始档案、衍生截图和个人收藏没有随开源版分发。程序的 MIT 许可证不授予这些第三方内容的权利。

## 个人导入

将有权使用的文件放入“待导入素材”，安装 `tools/requirements-import.txt` 中的可选依赖，再运行“导入素材.cmd”。工具保留输入文件，执行哈希去重和等比处理，将结果写入 `UserMedia`。

支持图片，以及可由配套 FFmpeg 转换的常见音视频。Godot 使用转换后的 JPG、Ogg Vorbis 和 Ogg Theora；把 MP4 改扩展名不能代替转码。导入记录和原文件路径只写入本机个人库。

游戏内“素材与关于”可以打开个人导入库。该功能不会自动替换中央展示图，也不会上传素材。提交代码和重新打包时，个人库与待导入文件均被排除。
