# 小鞠世界 · 开源试玩版 0.12.0-open.1

解压完整 Windows 压缩包，双击 `XiaojuWorld.exe`。请让 EXE、PCK 和许可文件保留在同一目录。游戏离线运行，游玩无需安装开发工具。

WASD 移动，Shift 跑步，空格二段跳。E 使用场馆服务，F 采集或上下交通工具，X 坐卧。B 打开背包，G 布置，R 旋转，F 确认，Esc 取消。

M 打开地图，N 折叠小地图。O 斜俯视，V 切换观察模式，右键拖动转向，滚轮缩放，Home 查看全图。P 拍照，F12 保存照片，F5 保存旅行，F6 调整昼夜天气。

本版图片、音乐和短片均为原创演示资源。私人版的真人照片、歌曲和 MV 未随包分发。个人素材可放入“待导入素材”，再运行“导入素材.cmd”；导入需要 Python 和配套依赖，具体提示见工具窗口。

公开版存档在 `%APPDATA%/Godot/app_userdata/小鞠世界 · 开源试玩版/save/open_v1`。个人导入库在程序旁的 `UserMedia`，移动游戏时可以自行保留该目录。
